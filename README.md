# QNZassets
Public assets and scripts for the Questionable Ethics custom weapons community.

Drag and drop the ``tf2classified`` folder provided in ``..steamapps\common\Team Fortress 2 Classified\`` to merge it with
the existing ``Team Fortress 2 Classified\tf2classified`` directory. If prompted, overwrite any existing files of the same name.

Because of size limitations, a mirror of the custom maps are hosted off of github, and can be downloaded here:
[tf2 custom maps](https://mega.nz/folder/0vkTQQbR#Ordrz7h-j6pw7wBnEBl4Ng)
