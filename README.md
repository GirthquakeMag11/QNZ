# QNZ
Repository for the Questionable Ethics custom weapons community on Team Fortress 2 Classified.

## Custom Assets & Scripts
Drag and drop the ``tf2classified`` folder provided in ``..steamapps\common\Team Fortress 2 Classified\`` to merge it with
the existing ``Team Fortress 2 Classified\tf2classified`` directory. If prompted, overwrite any existing files of the same name.

## Custom Maps
Because of size limitations, a mirror of the custom maps are hosted off of github, and can be downloaded [from this link](https://mega.nz/folder/0vkTQQbR#Ordrz7h-j6pw7wBnEBl4Ng).
The directory structure is similar to the **Asset & Scripts** archive, and the entire thing
can be dragged-and-dropped into one's game directory.

## VScript
The most current version of the VScript API as it currently exists in Team Fortress 2 Classified extracted directly from the game, formatted into five markdown documents for modding reference.
  - `vscript\Classes.md`
  - `vscript\Constants.md`
  - `vscript\Functions.md`
  - `vscript\Hooks.md`
  - `vscript\Members.md`
